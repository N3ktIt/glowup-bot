# Telegram Bot для продажи курсов

Бот для продажи курсов с оплатой и доступом только для купивших.

## Стек
- Python + aiogram 3.x
- SQLite (aiosqlite) для хранения покупок
- NOWPayments для крипто-оплаты (стартовый вариант)
- Хостинг: Render/Railway (бесплатно)

## Структура
Проект создаётся поэтапно. Первым делом настроим меню, оплату и выдачу доступа.
